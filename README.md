# Customer Churn Prediction & Analytics Framework

An end-to-end machine learning repository designed to analyze customer behavior, predict churn risks, and provide automated operational recommendations.

## 📁 Repository Structure
* **src/**: Production-grade python modules for data preparation, feature engineering, and model training.
* **notebooks/**: Experimental development scratchpads and Exploratory Data Analysis (EDA).
* **data/**: Local data directories (Ignored by Git for security/size constraints).

## 🚀 Setup & Execution
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Execute the pipeline models directly via your development notebook environment.
