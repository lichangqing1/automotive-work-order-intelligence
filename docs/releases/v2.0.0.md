# v2.0.0 — Measured AI Quality Platform

This release freezes the first complete, human-reviewed AI-value evidence for test generation and RCA.

## What is complete

- One authoritative FastAPI and SQLAlchemy runtime
- End-to-end AI-assisted testing with Jira review and retry-safe synchronization
- Three-run OpenAI test-generation and RCA experiments
- Complete human review and matched human-only baseline measurements
- Publishable, sanitized aggregate evidence under `artifacts/ai_value/`

## Measured decision

AI-assisted test generation improved coverage over the deterministic baseline and reduced measured human effort, but it did not exceed human-only coverage and every generated case disclosed at least one unsupported assumption. RCA reduced investigation time and produced useful recommended checks, but it failed accuracy and abstention thresholds. Both proposed AI-quality policies therefore correctly return `BLOCK`.

The release preserves gains and regressions. It does not present the evaluated model configuration as production-approved or suitable for autonomous use.
